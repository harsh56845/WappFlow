Secure by design — nothing stored on our backend

Customer phone numbers, templates, campaigns, suppression lists, and message dispatch history are saved only in this browser using sessionStorage. WhatsApp QR linking is also per browser/device (a private id in localStorage) — opening the app on another phone or laptop shows its own QR, not another device's linked number. Official Meta WhatsApp API Connection Guide

Step-by-step instructions to find your Phone ID, Business ID, and generate a permanent token.

Step 1: Create a Meta Developer App

Meta WhatsApp Business Cloud API requires an official Meta Developer App connected to your Meta Business Account.

1

Visit Meta for Developers

Navigate to developers.facebook.com and sign in with your Facebook account.

2

Click "My Apps" > "Create App"

Click the green Create App button in the top-right corner of the dashboard.

3

Select Use Case: "Other" > "Business"

Select Other as what you want your app to do, then click Next. Choose Business as the App Type.

4

Name your App and link Business Account

Give your app a recognizable name (e.g., "Acme Bulk WhatsApp") and link your Meta Business Portfolio / Account.

5

Add the "WhatsApp" Product

In your App Dashboard product list, find WhatsApp and click Set up. This enables the Cloud API engine.

Open Meta Developer Portal
Step 2: Copy Phone Number ID & Business Account ID

Both 15-digit numbers are located directly on your Meta App Dashboard under the WhatsApp API Setup page.

Where to find them: WhatsApp > API Setup

In the left sidebar of your app, click WhatsApp > API Setup. Under Step 1: "Send and receive messages", look at the dropdown and copy the values:

WhatsApp Phone Number ID: 105948372615243

Copy into "WhatsApp Phone Number ID" field.

WhatsApp Business Account ID: 109283746592019

Copy into "Meta Business Account ID" field.

Test Number vs. Live Registered SIM

• Developer Test Number: Meta supplies a free test number (+1 555...). If using it, scroll down to Step 2 (To) on the API Setup page and click "Manage phone number list" to add your personal phone number.
• Live Production Number: Scroll down to Step 5: "Add phone number" on that same page. Follow the prompts to add and verify your actual business SIM/phone. Once verified, you can send to any number globally.

Step 3: Generate a Permanent System User Token

⚠️ The temporary access token shown on the API Setup page expires after 24 hours. For uninterrupted production use, generate a permanent token using a Meta System User.

1

Open Meta Business Settings

Go to business.facebook.com/settings/system-users.

2

Add an Admin System User

Click Add. Name it (e.g. WappFlow System) and select System User Role: Admin.

3

Assign Assets to the System User

Click Assign Assets > select WhatsApp Accounts > select your account > toggle Manage WhatsApp Business Account (Full Control) > click Save Changes.

4

Generate Token with Required Permissions

Click Generate New Token. Select your app. Set expiration to Never. Check these two required permissions:

whatsapp_business_messaging
whatsapp_business_management
5

Copy the Generated Token

Copy the long string starting with EAAG... and paste it into Meta Permanent System Access Token in WappFlow Settings.

Step 4: Configure Live Webhook Callbacks (Optional)

Webhooks enable real-time delivery ticks (SENT ➔ DELIVERED ➔ READ) and process inbound customer replies (e.g. STOP opt-out compliance).

1. Webhook URL (Callback URL):
https://your-domain.com/api/webhooks/whatsapp

In production, this must be an HTTPS URL reachable by Meta (e.g., your public domain or ngrok tunnel during local development).

2. Verify Token:
whatsflow_verify_token_secure

Enter this exact verify token in the Meta Webhook configuration modal.

3. Subscribe to Webhook Fields:

Under Webhook fields, click Manage and click Subscribe next to messages.
